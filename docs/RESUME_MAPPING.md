# 简历与公开组件对应

简历描述整个平台经历，公开仓库只展示 Agent 子组件。此仓库不复制私有平台，
文档中提到的技术也不能全部视为本组件已集成。

| 简历项 | 当前组件证据 | 平台/后续验证 |
| --- | --- | --- |
| LangGraph、任务拆解与工具调用 | Runtime、五类工具、技能、控制流测试 | 真实模型规划质量另评估 |
| Qwen3-VL-8B | 已通过真实模型工具调用、审批恢复与报告；合成数据和实际 VIDEO/PG 空快照均联通 | 非空数据/图片与模型质量仍需验证 |
| 数据统计与轨迹 | 合成 Pandas 适配、确定性报告、17→34 对比 | VIDEO 的 SQLAlchemy/PostgreSQL 数据源在平台 |
| Faiss、MinIO、人脸模型 | 图片检索接口和隐私/候选边界 | 模型、索引、存储与准确率属于 VIDEO |
| Vue 3、图片上传与可视化 | 对接契约、结构化报告和统一 API | 完整界面在平台 WEB；本仓库不包含该界面 |
| 中断/恢复、记忆与回放 | SQLite 重建、审批绑定、有限偏好、回放测试 | 多实例单写、持久图片与生产保留策略需宿主 |
| 多 Agent | Planner/Reviewer/Reporter 模型角色 + 确定性 Analyst | 非四个自治进程，审核不代表独立 DB 真值验证 |
| MCP | 冻结工具目录、服务隔离、Schema 校验、模拟 Provider 测试 | 实际传输与认证由宿主 Provider 实现 |
| Kafka/Redis | 本组件未接入 | 教材和平台公共模块是另一层证据 |
| Docker/Nginx | 已通过离线镜像、Nginx 容器、真实模型+合成数据请求及同容器重启检查 | 不是完整平台部署/压力验证；见 VERIFICATION.md |
| RCVR 研究 | 未集成完整 RCVR | 研究仓库、基准和数值应独立提供证据 |

适合描述本组件的表述：

> 基于 EasyAIoT 平台服务边界实现 LangGraph 人脸分析组件，提供受限工具编排、
> 可复算报告、审批与检查点恢复，并通过合成数据和本地 HTTP 协议测试验证关键路径。

真实 Qwen/VIDEO、平台前端与研究结果应分别说明验证范围，不使用合成演示替代性能或准确率证据。
